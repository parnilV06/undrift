# UNDRIFT

Live frontend-backend API contract intelligence for the developer workspace.

## Repository Structure

- `packages/core` — reusable contract extraction, matching and drift-analysis engine.
- `apps/vscode-extension` — VS Code developer experience: diagnostics, quick fixes, sidebar, reports and workspace integration.
- `examples` — controlled demo applications used for development and benchmarking.
- `tests` — shared test fixtures and integration tests.

## Current Scope

The hackathon prototype targets React/TypeScript frontend projects with Node.js/Express/TypeScript backends, with limited Prisma schema awareness.
